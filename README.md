# Skye Gui — Game & Interactive Design

Personal portfolio with four HTML5 games, galleries, case studies, a 60-second showreel, and interactive artwork comparisons.

## GitHub Pages

Repository: `ShijieGui/shijiegui.github.io`.

Keep `index.html` at the repository root. In Settings → Pages select Deploy from a branch, `main`, and `/ (root)`. An empty `.nojekyll` file preserves the prebuilt website without Jekyll processing.

Expected address after publishing: https://shijiegui.github.io/

Website files and artwork are provided for this portfolio. Public availability does not grant permission to reuse the artwork or games.
